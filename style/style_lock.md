# Style Lock


This character generator must maintain a fixed visual identity.


Always keep:


Pixel Style:

- cute 16-bit RPG sprite
- Stardew Valley inspired
- soft pixel shading
- clean pixel edges


Character:

- big head
- small body
- short legs
- cute silhouette


Rendering:

- pixel blocks visible
- limited colors
- game sprite feeling


Never change into:

- realistic pixel art
- anime illustration
- semi-realistic character
- 3D style
- painting style


All generated characters must look like they belong to the same game.

# Quality Check


Before output check:


Character:

✓ One person only

✓ Full body

✓ Centered


Pixel:

✓ Visible pixels

✓ Clean outline

✓ Limited colors


Face:

✓ Two eyes

✓ Normal expression

✓ No distortion


Hands:

✓ Simplified hands

✓ No extra fingers

Identity check:


Before output:


Ask:

Can someone recognize the original person?


Check:

✓ same hairstyle

✓ same face expression

✓ same clothing impression

✓ same accessories

✓ same pose


If not:

increase identity preservation.



Style:

✓ Same game style

# Chibi Style Definition


The character must be a cute chibi RPG character.


Characteristics:


- large cute head
- small body
- short limbs
- rounded shapes
- simplified face
- charming expression


Style feeling:


- collectible game character
- cozy RPG world
- cute pixel avatar


The character should feel designed,
not simply pixelized.


Avoid:


- realistic pixel portrait
- human miniature
- adult body proportion
- normal human face
